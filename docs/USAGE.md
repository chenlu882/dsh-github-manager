# 新手操作文档

这是给小白准备的 DSH 插件。需要先安装 DeepSeek Harness；当前开发验证版本为 `0.2.1-rc.3`，其他宿主版本可能需要适配。

## 安装

1. 打开 DSH 的 Plugins 页面，找到“添加插件”。
2. 填写 `github:chenlu882/dsh-github-manager`，按宿主提示安装。
3. 安装完成后重启 DSH，打开 Plugins → GitHub。

如果宿主版本没有对应入口，使用 README 中的 CLI 安装方式。安装失败时先记录宿主版本和错误信息，不要手动改动宿主缓存。

## 五个分类怎么用

| 分类 | 用途 |
|---|---|
| DSH 插件 | 查看 GitHub 来源的插件，通过宿主更新或卸载 |
| 外部工具 | 查看 npm 工具，检查版本、确认后更新，打开位置或复制路径 |
| Codex 插件 | 只读查看缓存与配置推断出的信息，打开位置或复制路径 |
| Git 项目 | 检查远程跟踪分支，确认后快进更新 |
| GitHub 源码包 | 按名称和目录特征识别下载的源码，查看位置 |

选择分类后点击“刷新”。找不到项目时，查看扫描范围；默认只扫描规定目录，并非搜索整个电脑。

## 更新

先检查更新，再阅读当前版本、目标和路径，确认正确后执行。检查结果十分钟内有效。Git 项目存在本地改动、缺少上游或分叉时会拒绝更新，请先自行处理仓库状态。

缺少 Git 时，插件会询问是否通过 winget 安装 Git for Windows，可能需要管理员确认。npm 更新可能执行目标包自身的安装脚本。DSH 插件更新或卸载后，宿主可能要求重启。

## 使用范围与反馈

插件不会删除 Git 项目、源码包或 Codex 插件。Codex 缓存记录不一定代表运行中的版本。源码包按特征识别，可能遗漏或误判。

欢迎在 Issues 反馈问题或提交改进。分享截图时仅保留功能区域，遮住聊天记录、用户名、个人路径、令牌和其他隐私。
